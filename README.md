# Viva Galería — tema Shopify para Viva la Home

Tema Online Store 2.0 para [vivalahome.store](https://www.vivalahome.store), con la estructura de una galería de láminas: hero con flechas, bandas topo, carruseles de colecciones y productos, banner partido, promesas, opiniones, tarjetas de servicio y "Visto en Instagram".

- Paleta: crema `#F7F3EE`, arena `#EFE8DE`, topo `#A89478`, tinta `#231F1C`, etiqueta amarilla `#F2D16B` (todo editable en *Configuración del tema → Colores*).
- Tipografía: Jost + Cormorant Garamond (hay otras combinaciones en *Tipografía*).
- Los formularios de personalización (`snippets/vlh-*.liquid`) vienen del tema Horizon anterior, y los bloques de producto los cargan. Se conservan las plantillas `product.simplif-v2`, `product.lamina-coleccion`, `product.packs-regalo` y `product.idea-personalizada`, para que cada producto siga usando la suya.
- Las portadas (`vlh-*.png` en *Contenido → Archivos*) se generaron con Higgsfield a partir de las láminas reales.

## Instalar como borrador
Shopify → Tienda online → Temas → Añadir tema → Conectar desde GitHub (esta rama). También se puede subir un .zip con las carpetas `assets config layout locales sections snippets templates` en la raíz.
